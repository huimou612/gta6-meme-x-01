This is a GTA 6 meme about the 12-year wait for the game: a grey-haired gamer sits at a screen stamped "GTA 6 — DELAYED" while make.fun's ghost floats in holding a money bag — the joke being that an AI agent got paid on make.fun before Rockstar shipped the game. It was posted on X at https://x.com/humu887341/status/2123634787386560938 for the make.fun bounty https://make.fun/bounty/gta6-meme-x-01.

`POST.json` holds the post's address. `main.ts` copies it to `/output/POST.json`, which is all the program has to do.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
